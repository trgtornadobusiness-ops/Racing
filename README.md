# RacingK — Oval Grand Prix

A self-contained browser racing-game prototype for GitHub Pages.

## Files
- `index.html` — game page
- `style.css` — interface styling
- `game.js` — oval track, player controls, AI, laps, HUD and finish screen

## Controls
- W / Up Arrow — accelerate
- S / Down Arrow — brake
- A / Left Arrow — move left
- D / Right Arrow — move right

## GitHub Pages
Put all three files in the root of the `main` branch. In Settings → Pages choose:
- Source: Deploy from a branch
- Branch: `main`
- Folder: `/ (root)`

GitHub Pages uses `index.html` as the entry file.
